# wpxC
winnpixie's C commons

A library of functions and types that don't exist in the C Standard library,
but might be useful to developers.

## Lists (+ related functions)
- wpxll, Linked Lists (LINKEDLIST, LLNODE)
- wpxbill, Bi-directional/Doubly Linked Lists (BILINKEDLIST, BILLNODE)
